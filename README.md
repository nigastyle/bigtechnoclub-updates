# BIGTECHNOCLUB · обновления живых обоев

Служебный репозиторий. Исходники программы здесь не публикуются — тут только подписанный манифест обновлений
(`wallpaper/update.json`), новости для виджета (`wallpaper/news.json`) и сами выпуски (вкладка Releases, туда
кладётся `BIGTECHNOCLUB.exe`). Установленная программа проверяет этот манифест сама, каждые несколько часов,
и обновляется без участия человека — подпись (ECDSA P-256) сверяется ключом, вшитым в программу, файл без
верной подписи и правильной контрольной суммы не запустится.
